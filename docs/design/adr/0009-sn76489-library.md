# ADR-0009: SN76489 PSG emulation library

- **Status:** Accepted
- **Date:** 2026-05-21
- **Related:** [03-psg-synthesis.md](../03-psg-synthesis.md), [ADR-0002](0002-ymfm-for-fm-emulation.md), [ADR-0003](0003-gpl-v3-license.md)

## Context

ymfm ([ADR-0002](0002-ymfm-for-fm-emulation.md)) emulates the YM2612 but does
**not** include an SN76489 PSG. The Genesis PSG is a Sega VDP-integrated clone
with a specific LFSR configuration (feedback `0x0009`, 16-bit shift register,
initial state `0x8000`). A separate library or implementation is required.
Candidates:

| Library | License | Notes |
|---------|---------|-------|
| `ValleyBell/libvgm` `emu/cores/sn764xx.c` | LGPL | Broad SN coverage; LGPL is GPL-compatible |
| `vgmrips/vgmplay` `chips/sn76489.c` | Not clearly stated | Battle-tested in the VGM ecosystem; explicit `FB_SEGAVDP` support |
| Custom implementation | MIT / public domain | ~150 lines from the public spec; no license ambiguity |

## Decision

Use **`ValleyBell/libvgm`** (`emu/cores/sn764xx.c`). It is **LGPL** — compatible
with the project's GPL v3 license ([ADR-0003](0003-gpl-v3-license.md)) —
battle-tested across the VGM ecosystem, and it covers the Sega VDP SN76489
variant. It is added as a git submodule at `third_party/libvgm`.

Only the SN76489 core (`sn764xx.c`) and the minimal libvgm shared headers it
depends on are compiled into the plugin — **not** the whole libvgm library.

The core is wrapped behind the `SN76489Wrapper` C++ interface defined in
`03-psg-synthesis.md`, so the backend stays swappable.

## Consequences

- libvgm's LGPL license is GPL-v3-compatible, so it can be committed as a
  submodule (see [ADR-0003](0003-gpl-v3-license.md)).
- The build compiles only the `sn764xx` core plus its minimal dependencies;
  pulling all of libvgm is unnecessary and avoided. The exact source/header
  subset is an implementation detail to pin down when the submodule is added.
- The `SN76489Wrapper` abstraction isolates `SN76489Engine` and the rest of the
  codebase from this choice; swapping to a custom core later (if libvgm's build
  footprint proves awkward) touches only the wrapper.

## Alternatives considered

- **`vgmrips/vgmplay` `sn76489.c`** — battle-tested with explicit `FB_SEGAVDP`
  support, but its license was not clearly stated; rejected to avoid committing a
  dependency of uncertain license to a GPL project.
- **Custom ~150-line implementation** — MIT/public-domain, zero license
  ambiguity; viable, and kept as the documented fallback if libvgm's build
  integration proves troublesome. libvgm's proven accuracy is preferred for the
  first implementation.
